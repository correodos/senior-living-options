# drafts/

Article drafts and the image inbox. Nothing here is part of the website.

- `drafts/<category>/<slug>.md`: draft written with the `new-article` skill, waiting for approval.
- `drafts/images/`: drop the generated image here as `<slug>.png` (or `.jpg`/`.webp`); the image
  prompt is `<slug>.prompt.md`.

Everything except this README is git-ignored. Workflow: `docs/NUEVO_ARTICULO.md`, section 0.
